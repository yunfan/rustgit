# 核心高级特性经验总结

1. **持久化与进程生命周期**：
   在 Rust 编写 CLI 工具时，底层的内存缓存 (`MemoryStorage`) 虽然带来了操作与计算 Tree Hash 的极快速度，但在 CLI 退出时不会主动持久化。如果是跨多条独立指令流转的工作流（如 `add` 后接 `diff` 或 `commit`），必须在产生缓存态的指令退出前显式发起对象落盘（持久化到 `DiskStorage`），否则下游进程会因无法重建引用关系产生严重的 `MissingObject` 或悬空指针。
2. **轻量级的 Stash 实现模式**：
   利用 Git 悬空引用（Dangling References）可以以极低成本实现 `stash` 栈。通过将当前状态封装为一个无需 HEAD 跟踪的正常 Commit 并串联为父子关系，即可免去专门维护复杂 reflog 的工作。配合内置的 `checkout_tree` 实现完美的工作区状态还原。
3. **差异化展示**：
   终端展示差异应保持极简。使用 `similar` crate 配合 `unified_diff().iter_hunks()` 解析，并借助 ANSI 转义码高亮增删字符，可以在百余行代码内完美平替原生的 `git diff` 显示格式。
